应届生如何挑选第一份工作？

从大三暑假到毕业答辩，应届生求职的完整时间表、简历四段式写法、海投方法和Offer打分法

Created2020-03-15|Updated2026-10-30|25. 年代秀&真人秀
Author:幽哥|Account:Zhihu
Word count:8.4k|Reading time:25min|Post View:

        

        

        

            

        

        


今天这场直播，海报上写的主题是”试用期”和”应届生如何挑选工作”。


试用期我不展开了，文章里写过太多。今天重点讲应届生。


实际上我这十几年来主要服务的不是应届生，而是往届生——那些背井离乡、在本地或者一线城市迷茫打拼的人。应届生有学校、有老师、有家长帮衬，我讲得一向不多。


但今天这一段，你听下来，转给任何一个应届生朋友，他找工作会快很多。为什么？因为书上不教这些，你父母不知道，学校就业指导中心更不会讲。他们能告诉你的，都是”先就业再择业””要做好职业规划””先去小公司锻炼锻炼”这类正确的废话。


好，直接上干货。


一，先纠正一个时间错误
应届生找工作，不是大四下学期才开始的，更不是毕业前三个月才开始的。


举个例子，你2021年6月毕业，那你的求职起点是2020年7月1日——也就是你的师兄师姐离开校园的那一天。


从那天起，你大三升大四，暑假两个月，只做两件事。


    

  • 第一件事：找一家公司给你”背书”。
    • 



你需要的是一家公司，能在你大四一整年、乃至毕业后的简历上，让你写这么一句：”2020年6月-8月，在某公司任财务专员/采购跟单/客服专员/IT工程师/设计师”。


能敲个章、能开出实习证明、工作证明，就够了。你自己不要真的去实习，纯浪费时间。


唯一的例外是五百强。大三下学期结束前，你就该去五百强的官网、去前程无忧和智联招聘的社招频道、去动用亲友关系，看能不能进五百强实习两个月。除了五百强，其他的一律不去，国企央企的实习也没任何意义。


    

  • 第二件事：做一份应届生简历。
    • 



怎么写，下面单讲。


二，应届生简历，就四块内容
应届生简历很简单，四段式，别搞花架子，什么”个人作品集””职业规划书””自荐信”，一律不要。


第一部分：基本信息。


写：姓名、性别、出生年份、目前所在城市、联系电话、电子邮箱。


注意几个点：


    

  1. 出生年份，不要写出生日期。1997、1998，写个年份就行。你岁数偏大就写年龄，22岁、23岁。
    2. 

  2. 期望职位、期望岗位、期望行业、期望工资、目前薪资、目前职位，全部删掉，一个字都不要写。你是学生，目前薪资是0，写出来只会让人家把你当廉价劳动力。
    3. 

  3. 目前所在城市要写，这是加分项。你在长沙读书就写长沙；你目标城市是上海，那就写上海。到时候人家打电话问”你在上海吗”，你说”我下个月过去，现在临时回学校办点事”，这就够了。
    4. 

  4. QQ邮箱完全可以用，别听那些”QQ邮箱不专业”的鬼话。
    5. 



第二部分：个人概述。


用”个人概述”，不要用”自我评价”。写三句。


    

  • 第一句写个人风貌：”活泼开朗，善于动脑，懂得创新，团结互助，富有创意。”
    • 

  • 第二句写你这四年的学业生涯：”四年机械制造专业理论与实务学习，参与过多个项目开发，并有过采购与供应链管理方面的实习经历，能熟练运用行业知识。”硕士毕业就写六年、七年。
    • 

  • 第三句写你的应届生属性：”英语熟练，计算机熟练，可适应出差，能在压力下工作。”
    • 



不管你熟不熟练，全部写”熟练”。这一句的关键是突出：我跟中年人不一样，我跟那些跳槽的师兄不一样，我年轻、能出差、能抗压。


第三部分：实习经历。


写两份，倒序。


最近的一份，写2020年6月到8月，三个月，在某公司做采购专员，职位描述写五条，越细越好，写得跟师兄师姐的跳槽简历一样。


再往前一份，写2018年1月到2月，寒假，在某公司做自动化设计专员、项目工程师。


记住，一律写”专员”，不要写”助理”。职位描述写四条，不要超过最近那一份。


第四部分：教育、培训和资质。


注意，叫资质，不叫证书。哪怕就是个证书，你也写成”资质”。


这一块写五条以上：


    

  1. 第一行写你的最高学历：2017-2021，某某大学，专业名称，学士学位。学院名一般不要写，除非你那个”某某文理学院”跟母校差了十万八千里，那就补上。专业名称后面不要写”专业”两个字，直接写”机械制造””供应链管理””学前教育”。末尾写上”本科学士”四个字——我是有学位的人。实在没拿到学位证的，就写”本科”。
    

    

    顺带说一句，每年一百个本科毕业生里，有三十个拿不到学位证，其中十个连毕业证都没有。拿不到就先去上班，跟单位说”证书要过半年一年才能提供”，不要解释太多。
    

    

    2. 

  2. 接着写你的第三个实习：2018年，某某公司，客户服务专员。
    

    3. 

  3. 再倒序写你的社团经历：2019年校学生会宣传委员、英语俱乐部副部长；2018年校写作协会副会长。
    

    4. 

  4. 女孩可以写舞蹈协会副会长，擅长舞蹈；男孩写IT培训、相关资格证书、计算机。男孩不要写体育，没用；环球旅游也没用。
    你骑自行车环法国跑一圈，没用。但你把它改成”环法自行车赛志愿者”，就有用了——说明你出过国、做过志愿者、英语乃至法语流利。
    有用的：英语、写作、舞蹈（女孩）、视频剪辑和自媒体账号（男孩）。
    

    5. 

  5. 最后两行：英语：CET-4/CET-6；计算机：二级/三级，实在没证就写”熟练”两个字。
    

    6. 



最后提醒一句：学校不要放在简历最上面，放到下面去。除非你是清华北大，或者全国前十的学校，那你可以把学校放最上面。


三，9月1日，简历上线
简历更新到前程无忧、智联招聘、应届生求职网等网站上，9月1日开始。


然后，秋招和社招一起上。


秋招是2020年9月到12月，大四第一学期。50%的时间给校招，50%的时间给社招。


校招参加哪些？国企、央企、事业单位，以及跟你们学校有合作的大型公司，挨个去。时间冲突的时候，选大公司去面。


这里说一句你父母绝对不会告诉你的话：只要是跟机关、事业单位、国企央企挂钩的单位，很多是可以不通过考试、通过面试进去的。包括你老家的机关事业单位，也包括上海的。原因不展开，你记住这句话就行。


社招用这六个网站就够了，其他的全部抛弃：


    

  1. 前程无忧
    2. 

  2. 智联招聘
    3. 

  3. BOSS直聘
    4. 

  4. 领英（LinkedIn）
    5. 

  5. 应届生求职网
    6. 

  6. 脉脉（人贩子的贩，不是默默的默）
    7. 



前期只用前三个就行。


社招的岗位，要求1-3年工作经验的，甚至5年的，全部投，不要害怕。你就是个学生，投了不亏。


四，海投的三个次序
第一个次序，按人数投。


先投目标城市里上千人的公司；过两三周，投五百人以上的；再过两三周，投一百人以上的。


一百人以下的，一家都不要投，浪费时间。注意，这个人数是公司在你目标城市的总人数，含工人和总经理。


第二个次序，按注册年限投。


先投在你目标城市注册五年以上的；两三周后降到四年以上；再往后三年、两年；到11月、12月，注册一年以上的也全投，哪怕2020年刚注册的也照投不误。


第三个次序，按是否本地实体投。


那种”在上海招人，但公司不在上海”的，只是一个办事处、小分公司，或者合同要跟总部签的，放到第四个月，也就是12月，再去投。


每天投多少份？50份。从9月1日开始，每天50份，投你的目标城市。


到大四下学期，也就是2021年1月开始，把精力倒过来：20%-30%的时间给校招，70%给社招，每天投递量从50份变成100份。


校招这一块要注意”抓大放小”。校内的校招参加，你所在城市的重点大学校招也参加。比如在上海，同济、交大、复旦这三家的校招全参加就够了，其他学校不要去，浪费时间。


到了12月，你的成绩单应该是这样的：


    

  • 校招：投递出去100家企业，大概能拿到5到10个offer；
    • 

  • 社招：每天50份×120天＝6000份。6000份投出去，大概会来200个面试电话，其中50家会通知你去面试。这50家你挑10家去，会有3家发offer给你。
    • 



哪怕这些社招岗位写的是”1-5年工作经验”，也会发offer给你。你信不信？你不要相信，也不要不相信，你就照做。过去十年碰到我的师兄师姐，大四和研三都是这么干的，目前还没有一个因为参加了社招而找不到工作的。


五，期望职位、期望行业、期望工资，怎么填
网站非要你填，你就这么填。


期望职位填三到四个：


    

  • 两个跟你的专业相关。比如你软件工程毕业，就填”程序员相关””数据分析与数据管理相关”；
    • 

  • 一到两个跟专业不相关但你喜欢的，比如”商务专员/商务代表”。
    • 



这四个职位不影响你继续投其他几十种职位，网站上的必填项而已，别当真。


期望行业填四个，能覆盖50%以上的职位：


    

  1. 互联网行业；
    2. 

  2. 设备制造/一般制造业；
    3. 

  3. 服务业；
    4. 

  4. 你喜欢的行业，比如航空航天、影视传媒。
    5. 



期望工资填一个区间，区间写大一点，落在对方的区间之内或者有重叠就行。


    

  • 一线城市，本科：6000-9000；硕士：7000-12000；
    • 

  • 省会城市，打个五到六折：本科4000-7000；硕士5000-10000。
    • 



六，概率论：一千份简历=20个面试电话
有群友问：我把简历改得很漂亮、跟岗位很匹配，是不是面试概率就高了？


扯淡。这是概率论，改不了的。


你投1000份简历出去，就是20个面试电话。除了保险、传销这些你要踢掉的，真正能去面试的有10家；这10家你都去面，会有3到4家录取你。


也就是说，录取概率是千分之五。所以你要投6000份。


无论你怎么改简历、怎么美化、怎么造假，都改变不了这五样东西：


    

  1. 你的学校改不了；
    2. 

  2. 你的学历改不了；
    3. 

  3. 你目前所在城市改不了；
    4. 

  4. 你的目标城市也就那么一两个；
    5. 

  5. 你的工作经验改不了——你只有实习经历。
    6. 



我2000年左右毕业那会儿，投一千份，大概200个面试电话，筛出100家去面，会有50家要我。时代就是这么一个轮回，现在我们是4个面试换1个offer。


网上那些”我面试从来没失败过”的，都是骗你的。你让他面试100次试试，也就30个offer，改变不了这个概率。


就像抛硬币，你抛一万次，肯定接近5000次正面、5000次反面。但你抛5次，这5次可能全是正面——**于是这个人就去网上发文章：”我抛硬币全是正面！”**错的，明白了吧。


所以知乎上的回答你要甄别：排名前三的高票回答，有待商榷，很多是自媒体为了转发、为了流量、为了打赏写的，跟淘宝销量第一第二是一个道理；第3到第8名，还有点干货；第10名开外，基本是抖机灵或者瞎说。


买东西你不要盯着销量第一第二，一个道理。


七，收到offer之后，报到时间怎么谈
有好的大公司，就先签，签双方offer。


然后跟对方商量报到时间：**”我是2021年7月5日来报到”，或者说明年春天、明年夏天来报到。不要说”我明天就能来”。**


我们在钻一个空子。


社招的本质，是弥补前任离职留下的空缺，或者新项目的新岗位，对方都要求立即报到或者一个月之内报到。而我们毕竟还是学生，要跟他说清楚。


那为什么秋招期间也能参加社招呢？因为大公司在做人才储备。


苹果、特斯拉这样的公司，招人并不是明天、下个月就要你来报到，它是把人才长期储备在人才库里：首轮面试、复试、终面，工资都谈好了，就是不让你来报到。什么时候有了新项目，或者老人离职、升迁了，一个电话、一个offer就叫你来上班。


这是人才战略储备式的招人方式，是顶级跨国公司在做的事。绝大多数公司，包括中国的绝大多数民企和国企央企，都是有了招人计划才去社招发布职位的。


所以我们要抓大公司。


到了5月1日前后，看看手头的offer有哪些，选一家签三方协议，向学校报备；然后回老家玩一玩，论文提交一下，答辩参加一下，就OK了。


插播一句：很多学校整个大四是不上课的，尤其是西部的一些双非院校，直接把学生放到某个一线城市去”实习”，那叫放养。身上带个一两千块，钱花完了、实习没找到，就直接回学校。


你不要觉得学校是在诓你，学校也是没有办法，招生难。你交了一万、一万五的学费，但你不去住宿、不占用教师资源，学校还省了成本；而”笨鸟先飞”，你比那些重点大学的学生多了一年的实习经历，也就是工作经历。心里有个数就行。


八，应届生和往届生，分界线是哪一天
2020年的应届生，如今已经过去半年了，记住这一点。


    

  • 体制内，会给你延长，国家规定大概两年之内你还算应届生；
    • 

  • 体制外，也就是市场经济这一边，从你7月1日离开学校的当天起，你就是往届生了。
    • 



为什么？因为过了8月、9月，你的学弟学妹就开始叫应届生了。你已经不是了。


2019年6月毕业的人，到2020年1月还认为自己是”毕业生”，扯淡。你比同班同学少了接近一年的工作经验，你不知道吗？等你去面试，发现面试你的主管居然是你同学，你就明白了。


我们95%的人，最终都要进入体制外工作。体制内的就业机会就那么多，只装得下5%的人。


进了体制外，你就要在大海当中奋斗，做一个弄潮儿。弄潮儿怎么做？参加一辈子的社招。


这里是最关键的一点，很多人一辈子都没想通：


你从1岁到22岁、23岁，整个学业生涯都在体制内做学生，你的思维也是体制内的。但你95%的概率要进入体制外工作。所以毕业后的头三年，你非常难过，大脑转不过弯。


你在网上、书上、知乎上看到的那些道理，绝大多数还是沿着体制内的思维，让你在体制外去奋斗。这两个东西格格不入，断层非常厉害，所以你会迷茫、会矛盾，这是正常的。


正常的迷茫期是36到40个月。反应快的一年，反应慢的要四到五年。这就是为什么毕业三年以上的师兄，跟你三年之内的不一样。


多看看我的文章。除了我的文章，没有任何一个人会写体制外的人生到底是什么样子。


硕士毕业稍微好一点。不是因为他书读得更多，而是他认知社会规律的悟性更高、识别度更高。当然，学历越高越容易上当受骗，那是另一回事。


九，offer怎么选？打分
手里有多个offer不知道选哪个？打分。


总分100分，六个维度：


第一项，工资，40分。


同龄人、同城市的平均年薪是20万，你拿到40万，就是40分；拿到20万，20分；拿到10万，10分。以此类推。


第二项，工作制，10分。


五天八小时、正常上下班，9分；不用打卡，10分；偶尔不来上班也不用报备，10分；能在家办公，10分；加班有加班费，5分；996没加班费，2-3分；007，1分甚至0分；住在公司、住宿费还要自己交的”创业公司”，0分。


第三项，企业人数，10分。


1000人，10分；500人，5分；100人，1分；50人，0.5分。


第四项，企业在本地注册年限，10分。


10年以上，10分；5年，5分；3年，3分；1年，1分。


第五项，行业，10分。


新兴行业，10分；一般行业，6分；一般制造业、餐饮，4分；差的行业，1-2分；骗子公司、数字货币，0分。


这里单独说教育培训行业：公立的学校，算事业单位，给7-8分；社会上的培训班，再大也给4分，跟一般制造业差不多。


第六项，家人支持程度，10分。


三个offer摆出来，父母觉得A最好，给10分；B中间，给5分；C最差，给0-1分。多问几个亲人，取平均分。也可以问我这样的人，问三个就够了，不要问太多。


应届生版本：工资那一项提到70分，其余六项各5分。


最后选总分比第二名高出10分的那个。找不到，就继续找，直到找到为止。


十，群友提问
问：招聘网站要填3-5个行业和职务，我投了这些之外，还能拿到面试机会吗？


全部投，概率是一样的。海投就对了，不管岗位和专业匹配不匹配，最终你的面试概率就是千分之二十。不要”应对”，你要做的就是海投。


问：简历被查看、被收藏了，算不算有戏？


都不算数。只认来不来面试电话。另外，你没投过的岗位却叫你去面试的，一律是骗子，不要踩。


问：海投之后接到电话，我记不得是哪家了，怎么办？


海投也要做基本功，三件事必须记住：一，这家公司叫什么名字；二，我投的是什么职位；三，这个工作在哪个区（上海的浦东还是闸北，惠州的惠阳，北京的海淀）。记住这三条，你就不会莫名其妙地接到电话。


问：体制内那些不用考试的岗位，是怎么来的？


就是补人头。原本这个岗位通过校招或考试招了人，后来这人能力不行、犯了事、或者被调查处理，岗位空出来了，这时候补人就不需要考试，通过面试就能进去。


我们这个项目愿意要应届生，招了50个校招生，到来年6月发现有三个人跳槽、两个人去了别的项目，这五个空缺就要补。补的时候看资质、看关系、看专业匹配度和面试发挥，很快就能进来。


体制内连央企国企加起来7000万人，怎么可能只靠每年五六万、十来万的校招和考试来补？更多的缺口是通过社招补充的，所以你在前程无忧、智联招聘上也能看到央企国企招人，只是不多而已。


问：在职如何提升本科、硕士学历？


分两条线。


时间线：


    

  • 本科毕业5年之内：去考全日制硕士，或者参加统考硕士；
    • 

  • 5年到10年：读比较好考的在职硕士，包括MBA；
    • 

  • 10年开外：读EMBA，或者申硕，或者报各个大学在中国设的报名点的海外硕士，拿个单证也行。
    • 



金钱线：45岁之前，只要家里有钱，都可以去国外，尤其是英联邦国家，读一个一年到一年半的硕士回来，花个30到50万，没问题。


本科怎么提升？很多双非学校当年设的专业，比如材料专业，一年能发2000张本科证书，但报名的人只有1300个，剩下700个名额怎么办？它就自主招生，通过外面那些培训机构招学生，来学校上一到两个学期的课，然后发证。证书学信网能查到，考试稍微简单一点，但毕竟也是学过、考过的。外面那些提升大专本科学历的机构，基本每家都有一两个学校在合作。


问：老家山东，在上海读书，想去北京的央企，没有关系怎么办？


关系是自己打造出来的，先天的关系都不能长久。


一，不要得罪领导；二，跟同事搞好关系；三，跟上级关系稍微好一点；四，慢慢把你所在城市的各个行业的关系搞好，包括校友关系、国资委里的师兄师姐；五，原来的同事升迁上去了，也是你的关系。


你看那些大厂的厂长，哪个是先天的关系？都是后天自己开发的。哪有什么从一而终的先天关系。刚毕业那会儿要靠一点关系进门，进去之后，师傅领进门，修行在个人。


问：要找本专业相关的工作吗？怎么跳槽拿到更高的工资？


肯定要找相关的，但不要只找相关的。你的职位分两类：


    

  • A类职位：跟你工作相关、你擅长的，写2-3个。你的面试概率会比别的稍高一点点，真的只是一点点；
    • 

  • B类职位：写5个。其中3个是你过去工作中打交道最多、频次最高的其他部门岗位；剩下2-3个是你喜欢的大公司里的岗位。
    • 



比如你是UI设计师，你特别喜欢苹果，苹果中国有个职位叫Outsource Specialist，你都不懂是干嘛的，但公司好，照投不误；叫Manager也照投不误。


投递的顺序是：先投职位高的，再投中的，最后投低的。先投这家公司的UI设计部长，一周没反应，投UI设计经理；再没反应，投UI设计和人机交互主管；再一周，投UI设计组长或者专员；最后才投UI设计助理。


应届生也一样，先投主管，再投专员，再投助理。别一上来就把自己定位在专员。


至于怎么谈高工资，那是倒逼法，我上一次直播里有专门四分钟讲这个，这里不重复。


问：目前工资怎么写？


在小城市，你就稍微夸一点，多写一千块没问题。而且我们跳到大城市，并不完全参照上家公司的工资，这里有个城市加成：你十八线城市的8000，约等于上海的1万。低于1万去上海，成本是划不来的。


谈高工资的具体流程是这样的：


    

  1. 先闭着眼睛拿到第一个offer，让他先出价。他出6800，你要7800，最终谈到7300，成交；
    2. 

  2. 拿到7300之后，把简历上”目前工资”从四五千改成**”保密”，期望工资直接改成9000-12000**。这样你就能谈到9800或者10500；
    3. 

  3. 拿到10500之后，再把期望工资改成12000-15000，这样就能谈到13800左右。对方问你”你两周前面试时才要一万出头，怎么现在跳到一万四了”，你就说”师兄给我介绍了个工作，已经超过一万了，我截个屏给你看”——把含10500那句话的截图发给他，他就给你一万二、一万三、一万四的offer了。
    4. 



这叫倒逼法谈工资，依此循环。拿到一万四，就可以谈一万六、一万八。


正常来说，本科毕业十年的人跳到上海，谈到两三万是正常的；本身在上海待了十年的，用这个方法谈到三万到五万，没问题。


问：投了当地世界五百强的子公司三个职位，收到两个电话，但HR说公司内部用的是同一个招聘系统，不能同时面，只能面一个，怎么办？


先挑你最喜欢的、或者工资最高的去面。另一个再约时间。这是正常的，因为子公司的不同职位是不同的人在安排。


但你入职或者拿到offer A之后，还想再争取offer B，这就不大可能了。就像你同时跟两个姑娘谈恋爱还要领证，不好。


问：领英和脉脉，除了投它推的职位，还能怎么用？


除了推的职位，上面也有搜索功能，你就搜职位，然后加一些人事和主管的好友，个别发发私信，问一句”你有没有职位”。


发100份私信出去，估计也就10个答复你。但10个也是机会啊。


至于这个软件具体怎么用，那就别问我了，自己研究、百度，或者去问别人。这不是我擅长、也没必要较真的地方。


问：我是大四的，老家体制内是不是性价比最高？那还要不要提升学历？


是的，老家体制内性价比最高，本科就够了，主要就是考进去。


进去之后，你不是去提升学历，是考证。三个有用的证：一，律师资格证；二，CPA注册会计师；三，你那个岗位上，单位里的资深同事或者领导有什么证，你就去考什么证。


2028年之前，中国的工资购买力都是不怎么高的，所以一定要赚高工资，理想情怀先抛到一边。2028年之后工资购买力会提升，房价会显得不高，可能本科毕业起薪就是一万五、两万。


买不起房不用特别着急。你前面这五年或者十年，在一线城市赚个两百万，为什么要去小城市赚三四十万？第八年带着两百万回小城市，我跟他的工资一样是五六千一个月，但我这两百万可以投资、可以理财，甚至拿一线城市或者昆山的租金收入。


体制内的优势主要在35岁之后开始展现：一，不怎么会失业；二，当下的工资并不低。


我们毕业那会儿，进外企三四千，进体制内只有八百到一千二，三倍的差距，所以那时候去体制外更好。现在呢？华为在你老家的分公司也就八九千一个月，而体制内工资三四千、四五千，加上补贴、年终奖、精神文明建设奖、补充公积金，已经接近华为的工资了。而华为是996，你在老家这八九千可是五天八小时。


所以正常来说，2020到2030这十年，公务员是首选，其次是国企、老师、事业单位。


问：国企、地方国企算体制内吗？


算半体制内。比如一家电器行业的国企，它在安徽当地就能给本科毕业三到五年的员工月薪上万，难以想象——因为国有企业有体制内的保护措施，不完全参与市场竞争，不需要996。


地方国企也算半体制内。比如南通地铁，它属于南通国资委，南通国资委归江苏省国资委管辖，一层一层的。烟草之类也是。


问：创业、开网店算不算创业？


都算，成功率都是2%-3%。投入成本不高也是创业。


但你可以用副业去做。主业工作不能是爱好，但爱好可以作为副业。不要拿主业、全职去创业开店。


问：毕业两年，做了一年多销售，想回去做技术员，发现得从头再来，怎么办？


你才毕业两年，怕什么。把你的简历做成三段：


    

  1. 一年半的销售；
    2. 

  2. 半年跟技术或者质量相关的工作；
    3. 

  3. 大四最后一学期的实习经历，在某家公司做机械设计专员、电气设计助理工程师之类，写三到四行。
    4. 



这样你的工作经历里就有三份，你现在去求职一个技术相关的工程师岗位，不正常吗？


面试的时候你就说：我做的是技术类销售，要看图纸，50%的时间在研究产品，还要参加项目会议，所以我是一个技术人员。


直接投就行了。


问：今年疫情会影响找工作吗？


肯定会。我建议大家：目前有工作的，先耐着性子憋一憋。


    

  • 5月1日开始更新简历；
    • 

  • 5月10日左右开始投递；
    • 

  • 整个6月到7月面试；
    • 

  • 7月15日左右提出离职；
    • 

  • 8月1日到8月15日前后入职新公司。
    • 



疫情最厉害的时间已经过去了。但尽量不要找外贸的工作。我们第一季度经济非常困难，欧美发达国家是第二季度难过，所以跟外贸、跟国外相关的行业和岗位，招人会比较少，试用期很不容易通过。尽量找内贸，互联网和在线的工作也可以做。


问：公司倒闭了，我在找同岗位的工作，但工资大幅下降，应该转行还是等到夏季？


早点找工作，跟失业一样处理。这份工作无论做了三个月、五个月还是八个月，等到十月份、十一月份行情好了再跳，顶多增加了一次工作经历而已。


但你的收获是实实在在的：一，完成了这几个月的收入；二，银行流水可以背书；三，简历里没有断档。


超过三个月的断档，人事会一直挑剔你，部门主管也会挑剔你。人事招人看四个要素：一，学历；二，毕业年数有没有断档；三，上家公司的知名度高不高；四，工资在不在预算之内。这四个有一个不符合，咔嚓，全部刷掉。


工资下降怎么办？用倒逼法谈工资，多投简历，一定要海投。跟你的工作相关和不相关的十个职位，全部投递。


你只投一个职位，工资很有可能下降；你投十个职位，工资肯定是上升的。


就像你一米七，想找个高个子女孩：你只在村子里找，能找到的最高的可能只有一米五九；你到县城里找，能找到一米六三；你到地级市找，能找到一米六八；你到全省去找，同龄、谈得来的，硕士毕业的一米七五都有。


你只盯着自己的专业和岗位去找工作，那就是在一个小山村里找高富帅、找白富美，怎么可能呢？


问：在合资车企上了半年班，看到同事晋升周期都很长，高工资或者经理都要七年以上，如何晋升？


两个方法。


    

  • 方法一：跳槽谈高工资。不管晋级不晋级，反正我工资高，心安理得。
    • 

  • 方法二：直接投递主管和经理的岗位。
    • 



任何公司的内部提拔都很慢：先试用期转正，再待两年，大概两年半时间，才有做主管的机会。所以你别等，直接去外面投主管、投经理，工资也能加上去，级别也能上去。




今天就讲到这里。应届生这一整套，从大三暑假到毕业答辩，你照着做就行。


你可以讲给你的同学听，但我告诉你，他们绝大多数是不能接受的。他们想去外企，想创业，想”实现自我”。这很正常，因为他们还在用体制内的学生思维看体制外的世界。


没有办法，这是正常的。


End
