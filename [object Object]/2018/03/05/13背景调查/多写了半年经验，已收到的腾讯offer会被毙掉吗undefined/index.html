多写了半年经验，已收到的腾讯offer会被毙掉吗？

Created2018-03-05|Updated2026-08-29|13. 背景调查
|Word count:2.1k|Reading time:6min|Post View:

这个得就事论事，从大到小，挨个分析，结果一看便知。

【一，背景调查重要不重要？】

我在2005年，入职一家五百强外企，并没有做任何背景调查。

在2009年，我入职一家中型外企，公司除了收了离职证明和盖章的工资条之外，也没有要其他东西。

2016年我又跳到了一家大外企，也算五百强吧。但却有着严格的背景调查要求，甚至需要我提供实线和虚线汇报的俩领导以及HR这三个人的联系方式，需要他们每个人的姓名、职位抬头、座机、邮箱、手机号码和座机。我问了下，他们还真的挨个去打了，不但在发Offer之前新公司HR打过，入职前后的第三方背景调查公司，也分别联系他们查了我。

2017年，我在知乎和头条分享了一些职场经验，很快不少人加我微信咨询职场问题，至今平均每天一个来问背调问题。

以上这个编年体，说明，背调正在成为标配，不仅仅是外企、上市公司和国企，尤其BAT这样的顶级公司，肯定是要背景调查的，而且很严格。

所以，毫无疑问，隐瞒了工作经历，腾讯是很重视的，处理不好，这offer当然会被毙掉。

【二，背景调查分哪几种，一般什么时候进行？】

背景调查，你不碰到就不要紧，轮到你的时候，就开始慌张了。我们来看下，企业从新出现一个岗位，到新人入职转正填补这个岗位空缺，是一个怎样的流程？示意图如下：

招聘职位发布—>筛选简历—>初试—>复试—>背景调查A（薪水调查）—>工资谈判—>发放Offer—>背景调查B（学历审查）—>录用入职—>背景调查C（第三方背景调查完成）—>试用合格—>工作转正。

这样一看，就很清晰了，背景调查主要有三次，各有侧重点。

背景调查A，发生在发给你Offer之前那几天，主要是HR调查你的过往工资，这个环节用英文描述叫做Reference check；

背景调查B，发生在你报到当天进入部门之前，主要是HR调查你的过往证书，这个环节用英文描述叫做Registration Check；

背景调查C，发生在你入职后试用期转正前，主要是第三方背调公司调查你这个人的全部职业信息真伪，这个环节用英文描述叫做Background Survey。

很明显，大家求职时最担心，也是你现在最担心的，就是这最后的调查C，也就是第三方全面的背景调查。

【三，第三方调查是什么意思？】

中国人，你懂的，从小到大会碰到无数次“我不知道啊”“也没人告诉我啊”“政策一直在变”等等。所以，即使你一切都是真的，你的腰杆也没那么硬，你的潜意识里知道自己肯定有盲区，有不符合政策的地方，也就是，鲁迅先生说的那个“小”字你会担心被人查出来。所以，当你听到“第三方调查”的字眼，内心就忐忑了起来。

第三方，就是站在公正的立场，从多个角度来对求职者的履历等各方面进行验证，验证就是查证你这个人的真伪，包括简历中内容的真实性。这种公司不带有猎头、HR或者用人部门主管的私心，也是三权分立的体现，这才能确保招到合格的好人才，而不是关系户裙带关系，后者会影响一个建立了现代企业制度之公司的发展。

市场经济在中国发展了40年，已经日臻成熟，中国往后的职场，第三方这种更专业的背景调查，将会成为新员工入职的标配流程，不仅仅是销售、采购、财务这样的敏感部门，也不仅仅是部门主管以上的高级管理者，而是包括所有部门包括作业员在内的所有员工，都要做背调。

举例来说，苹果公司在国内是请的中智来背调，腾讯主要请全景求是背调公司，阿里则主要请文轩商务咨询公司，迪士尼用的汇华调查公司，上海周边很多外企和上市公司请上海外服做背调，等等。第三方做的，都是很全面的调查，包括履历和是否有犯罪记录在内，都会查，并不是HR小姑娘跟你说的“很简单的调查”。

【四，调查报告是什么样子的？】

如下这截图，就是1份真实的第三方背景调查报告节选，总计9页，这是第3页。

这家第三方背调公司叫做FAD，中文名叫做首优调查。截屏中红色的XX就是不符合项。本文题目这位帅哥担心的，就是第一个X，也就是入职日期，他作假了，误差半年。图片上这位求职者也作假了，她面试的是采购主管，她的误差更大，将2013年3月5日，写成了2010年10月份。

【五，调查哪些内容？有作假被发现了怎么办？】

先从战略来看，公司录用你，实际上主要看你的硬资产（学历、经验、上家知名度），再看面试情况，能到第三方背景调查这一步，说明你的“硬件”已经达标、“技术考试”也已经过关。后面的背调，属于“政治考试”类别，政治考试不是主要科目，只是确认你这个人的真伪。

再从战术来看，背景调查里面有违法犯罪记录、年龄、学历、工作年数、前雇主的工作起止日期、抬头职务、工作内容、社保情况、离职原因、工资数额等等“硬指标”，这些不假，你就大体是真实的，能过了。剩下还有人事信息、前领导评价、上上家领导评价、期间奖励奖项情况等等软指标。

一般担心最多的，就是怕前领导的评价，怕上家领导说自己的坏话。其实不用怕，对于新公司是否录用你，任何一个调查点都只占很小的权重，无论是前领导评价这一项为0，还是你这样的入职时间不符，你也都有其他90+的分数撑着。

具体这分数，可以量化不？能有多少分？看下表。

如果HR拿着背调报告来找你，无论你有几个X，都挨个书面发邮件解释，即可，你得有心理素质。比如这个入职日期提前了半年，可以说因为实际工作是发生的，只是没要公司交这半年保险而已，多数情况下都能过关。比如上面FAD那个例子中，这位美女求职者五六个红X，也一一解释通过了。

【六，腾讯会不会取消Offer？】

最后一个可能，就是腾讯的HR追着你这半年作假不放。

你的方法是请她去咨询下部门领导的意思，也就是你的面试官，他对你的Offer甚至试用期的去留，起着生杀大权的作用。每家公司都会给部门经理一定的权限，招人也是为他们部门招的。

现实中，我做部门经理时，也好几个新员工简历造假了，还有学历造假的，我大多放他、她一马，因为我们是在员工入职后才出第三方调查报告，我比较仁慈，怕他们重新失业求职，得好几个月的失业期。

所以，如果在最终无法解释的情况下，你问“腾讯会不会取消Offer？”这取决于部门主管，你试着跟他建立下私人关系看看。

试试，机会属于有准备的人。
